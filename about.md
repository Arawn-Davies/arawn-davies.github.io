# About

I am Arawn Davies, a systems and software developer based in Leicester, UK. I
have commercial experience in platform modernisation, DevOps, application
security and systems integration, with an MSc in Cyber Security and a First
Class degree in Computer Science.

I enjoy working across application code and infrastructure, particularly where
security, automation and maintainability need to be considered together. I am
also interested in systems programming, open-source development and
virtualisation.

## Experience
**Developer (AppSec & DevOps)** — ExamTrack Ltd *(2026 – present)*. Working with
the development team on the modernisation of a multi-engine Ruby on Rails
application. My focus is application security and DevOps, including CI/CD,
containerised environments and static and dynamic security scanning with
Brakeman and OWASP ZAP. I also contribute to Rails development, testing,
performance work and technical documentation.

**Technical Specialist** — Leicestershire County Council *(June 2022 – August
2023)*. Full-time work developing internal tools and data-processing solutions
with C#, PowerShell and PostgreSQL across council departments. This included
automating a manual 21-day process down to 72 hours and building QGIS geospatial
data pipelines used by live public-sector services.
