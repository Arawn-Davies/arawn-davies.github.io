# microCMDB

microCMDB is a lightweight Configuration Management Database — a compact, self-hostable way
to track assets, configuration items and the relationships between them without the weight
of an enterprise ITSM suite.

Built from my placement-year experience with enterprise IT and asset management, it focuses
on a clean data model, simple APIs and being easy to run anywhere.

**Status:** in active development.
