# Medli3

Medli3 is the third generation of the **Medli Operating System** — a managed OS written in
C# that I've developed off-and-on for over a decade. It compiles .NET Common Intermediate
Language straight to x86 machine code, letting C# applications run on bare metal without the
overhead of Windows, macOS or Linux.

This generation builds on lessons from earlier Medli versions and my contributions to the
Cosmos and Aura operating-system projects.

**Status:** in active development.
